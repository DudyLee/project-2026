# 提议：用现有数据降低平均照度误差，重点诊断BM432

状态：**仅方案，未批准执行训练**。2026-11-08。当前请求只授权读取已有数据和预测作分析；本次新增估计器拟合与模型预测均为0。

## 已有证据与目标

v8的S1平均照度留房间MAE为64.380 lux，BM432为222.832 lux；其他六房间MAE之和227.827 lux。如果其他房间保持不变，要实现7房间平均MAE<50，BM432必须降到122.173 lux以下，即下降约45.2%。这是条件算术，不是效果承诺。S1只是现有平均分最好的开发对照，未替换部署模型。

BM432中真实照度>300 lux的记录约占40.0%，贡献S1绝对误差约86.1%；>1000 lux的2150条记录约占12.3%，贡献47.6%，该区间MAE865.144 lux且全部低估。DNI=0时S1 MAE6.111 lux，DNI>500时586.942 lux。四个角度均持续低估；不能解释为只有一个角度或几个异常小时。不能用真实照度区间作为推断路由条件。

BM432全年小时平均照度393.682 lux，显著高于其余开发房间；同为−Y的BM441与LM608约45.038和106.749 lux。BM432的遮挡比例0.266低于这两个房间，玻璃/地板面积比也更大。单纯宣称“没有该朝向”不适用于BM432；问题更可能涉及该朝向下的高采光强度、遮挡和几何组合覆盖不足。源几何/网格差异与log损失作用仍是待检验解释，尚不能归因为某一个因素。

已有v5向树模型增加玻璃/地板比、窗数、平均窗面积没有稳定提升；v7在旧特征上比较过原单位L1。下一轮应明确检验不同的机制，不能把这些旧试验重命名为新方法。

## 建议只研究E_mean_lux，三组新候选

保留v8 T1（方向交互＋XGB log1p）和S1（方向交互＋样条Ridge log1p）的完整外层预测作为匹配参照，并保留T0部署方法参照。其他四个输出不变，不搜索融合权重或房间ID路由。

| 候选 | 输入/目标 | 可检验的问题 |
|---|---|---|
| A | v8 F1；XGBoost直接预测lux，L1损失 | 加入方向交互后，消除log压缩能否减轻亮工况低估？这是v7原单位L1在新F1表示下的明确对照，不保证有效。 |
| B | F2；与A相同的原单位L1 | 把房间采光强度代理与逐时辐射显式组合，能否改善高亮房间？ |
| C | F2；预测归一化照度E/q，推断乘回q；加权L1 | 用输入已知的房间尺度承担亮度差异，能否减少树模型跨房间幅值迁移困难？ |

固定定义：

```text
q = (Glass_Area_m2 / Room_Area_m2)
    * (Annual_Incident_Shaded_kWh_m2 / 100 kWh/m²)
H = EPW_DNI_Wh_m2 * cos(radians(Solar_Altitude_mid_deg))
F2 = F1 + [q, q*EPW_DHI_Wh_m2, q*H]
C训练标签 = E_mean_lux / q
C预测 = q * max(predicted_normalized_illuminance, 0)
```

q为无量纲经验尺度，参考值100固定，不从BM432输出估计。F2使用现有BIM年度受遮挡辐射字段，原始输入由13变为14列，编码/交互后由F1的21列变为24列。年度辐射不等于逐时窗面辐射或lux，q也不是真实采光系数；不根据BM432误差反推物理北向或逐时入射量。

现有七房间q均为正。先核对TRAIN行的年度字段与已有BIM表相符、在同一房间四角度/全年内恒定、以及不由室内照度目标反算。该字段已存在于476房间BIM表，但原始计算来源仍须披露；只能宣称对具有相同可用字段的房间适用。不能为本轮新跑辐射模拟。若输入来源检查不通过，记录B/C未执行，不从目标反推替代值。

C的L1样本权重设为q/训练折平均q：因为q×|E/q−p|=|E−q×p|，这使归一化标签的损失与原单位绝对误差成比例。归一化不使用真实均值、Room_ID或BM432专用系数。尺度变化仍会改变树的划分/正则化行为，收益必须实测。A/B使用等行权重，七房间本身行数相同。所有评分恢复为原始lux。

每组仅比较depth3/5，其他XGB参数沿用冻结的0.1公共设置（150棵树、learning_rate0.07、min_child_weight100、reg_lambda10等），目标改为reg:absoluteerror。不增加样条结点、模型家族、特征清单或额外采样权重。L1实现见[XGBoost 3.1官方参数](https://xgboost.readthedocs.io/en/release_3.1.0/parameter.html#learning-task-parameters)；文档仅确认算法支持，不是性能证据。

## 按房间选择与评估

- 仅7开发房间；BM532、BM702、BMG26不加载数值、不训练、调参、预测或评分。它们此前被观察，不称为新的未见测试集。
- 仍做7折留一房间与3组留一朝向。+X/BM223折复用，共9个唯一外层问题。
- 各候选的depth在外层拟合房间内用3折GroupKFold选，按内层房间等权原单位MAE最小，完全并列取depth3。外层房间仅评分；尤其留BM432时不允许用BM432标签校正倍率、偏差、选深度或早停。
- 当前计划最多162次内层拟合（9×3候选×2深度×3内折）和27次外层拟合，共189次；原参照在核对来源/键/划分后复用，无全7房间部署重训。
- 全部候选完整报告，不仅汇报BM432。除两种验证的平均/最差MAE、逐房间MAE、RMSE、偏差外，重点报告DNI区间、10–14时、四角度，以及事后真实照度>1000 lux区间；附误差≤50 lux的比例与绝对误差P90。
- 不删除亮工况、不改真实值上限、不用缩小评估时间/角度范围达到50，不按随机逐时划分评分。

## 达标与停止规则建议

区分研究目标和替换条件。主目标是留房间平均MAE<50 lux、BM432≤120 lux（与条件预算约122一致，取整后的探索目标）；还须报告其他六房间是否改变，不能将该条件预算视为独立保证。

若要进入替换候选，建议同时要求：主验证整体最差MAE不超过v8 S1的222.832 lux，至少5/7房间较T1不恶化；留朝向平均MAE不超过T1的84.034 lux、最差MAE不超过T1的224.674 lux。这些是提议的冻结规则，尚未获批，不在结果出现后临时修改。多个候选达标按整体最差MAE、平均MAE、A/B/C顺序选。未达50但有收益，应如实归为局部进展，保留原模型。

只做这三组有限对照。若高亮低估仍无法缓解，停止无新信息的参数扩张；结论应是现有输入/房间覆盖尚不足以支持目标，而不是追加BM432倍率。下一步可核对已有源模型/网格资料，仍不追加模拟。
