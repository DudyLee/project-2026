# 试用版 0.1：冻结与训练协议

用户于2026-11-08批准：“用7个开发房间训练固定模型，封装四个角度、五项指标的统一预测接口，三个测试房间继续封存。告诉我怎么使用。”

本轮把保留的模型方法制作成可调用的软件包，不继续扩大v7的优化搜索，也不宣称改善了跨房间误差。配置在训练前写入 `configs/trial_v0_1.json`。

1. 仅载入7个TRAIN房间122,640行。逐行检查Sample_Role，TEST行在数值转换前跳过；不预测、评分或查看TEST目标分布。
2. 固定平均照度为XGBoost/log1p、P10为Random Forest/relative。各自在原先两个参数候选中做7折留一房间参数选择，以原单位的房间等权MAE最小者冻结；并列按配置顺序。这里所有验证房间属于开发集，选择后的分数存在选择乐观性，不是独立测试。保留各候选逐房间结果和预测以便复核。
3. F300、FUDI、PV固定v1的HistGB参数，不再调参。全部参数冻结记录写入后，用全部7个房间训练6个估计器，形成5个输出。P10自己的RF均值分支不替换为独立XGBoost平均照度输出，不使用推断时的真实均值。
4. 13项原始特征编码成15列。接口输入12项非角度特征，内部补入0/30/60/90°。Room_ID和Request_ID只作标识。接口拒绝真实输出、调用者自填角度、缺失/非有限/非法值以及三个封存Room_ID。
5. 范围提示只来自TRAIN输入。范围内不代表可靠；输入组合、天气来源及跨房间误差仍可能不适用。保留未核实EPW、时间、北向和百叶定义提示。
6. 使用TRAIN特征做完整四角度一致性检查、独立预处理核对、模型重载、CSV/JSON/Python入口一致性、批处理与单条一致性和非法输入检查。训练拟合分数不充当泛化分数。接口不读原始数据、不联网、不自动控制设备。
7. 新文件放在trial_v0_1命名空间；旧实验文件原样保留。记录源码/配置/源数据/模型SHA-256、版本、训练房间及行数，输出使用说明和TRAIN示例。

本轮预定参数选择42个估计器拟合（XGB 2×7 + RF双分支2×2×7），全7房间重训6个，共48个。接口验证无需再训练。三测试房间 BM532、BM702、BMG26 始终封存。新天气年、其他建筑、其他角度/离窗距离和实际动态控制不在已验证范围内。
