# 后续工作重点：模型性能

2026-11-08用户明确：“我不需要做可视化的部分，我仅需要把我们的模型训练好，有很好的性能即可。”

## 当前优先级

- 后续资源用于数据/特征核对、逐目标训练、跨房间验证和误差改进。暂停新增可视化、仪表盘、界面、演示与集成开发。
- 交付训练代码、固定模型、可复现实验配置和简明数值结果。已有推断入口保留作为调用和验证工具。
- “性能好”首先指按房间留出的预测性能；全7房间拟合成功、软件一致性或训练集拟合分数不能替代泛化成绩。
- 同时关注7个开发房间的平均MAE、最差房间MAE和逐房间变化，辅助报告RMSE/R²。不把不同单位的5项误差合成一个准确率。
- 沿用既有开发替换条件作为候选筛选规则：最差房间MAE至少下降10%、平均MAE不增加、至少5/7房间不恶化。这是研究比较规则，尚不是经用户确认的绝对工程误差容限。

## 证据与下一步

v7的5个输出均未通过全部替换条件。试用版0.1已全7房间重训和封装，但没有新增独立泛化证据。当前应保留已验证的比较参考，不将可调用误称为高精度。

已有直接/相对P10、目标变换、几何代理、RF/XGB/HistGB和最差误差选模比较未带来稳定的整体提升。后续优先核对既有房间/窗户几何、原传感器结果以及天气和时间来源，见 `docs/data_requests/geometry_and_simulation_sources.md`。真实房间进深、窗户位置等文件目前尚未确认取得；缺失几何是否改善精度仍需实验验证，不能提前承诺。

新特征须可追溯、在待预测房间可取得，且不得使用真实输出或房间ID替代物。得到可用信息后冻结小规模消融/对照方案；参数选择按房间分组，外层留出房间仅评分。避免在同一7房间上无止境扩展调参，并继续遵守既有停止规则。

暂不追加模拟；BM532、BM702、BMG26继续封存。最终方法与评价方案确定后，再另行按约定安排独立测试。本次优先级修订没有启动新实验或改变现有模型。
