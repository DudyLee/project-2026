# 跨房间特征与P10预测：已批准协议

## Material Passport

- Origin: academic-research-suite / experiment-agent
- Mode: approved execution of the four-group plan
- Approval: 用户“批准 先按照你的思路修订一下”
- Protocol status: frozen before v5 training; outcome pending

本轮限定为7个开发房间的两个照度目标，不追加模拟，BM532、BM702、BMG26始终封存。环境沿用项目内独立conda，不安装或更新依赖。

## 两个控制变量

1. 特征：原B13（编码15列），或增加玻璃/地板面积比、窗户数量、名义窗面积/窗户数量（16项输入，编码18列）。新增项全部由推断时可取得的输入计算，不使用照度标签或房间ID。
2. P10处理：现有相对P10，或直接asinh(P10/1 lux)回归。平均照度始终log1p。A=原特征/相对P10，B=增强特征/相对P10，C=原特征/asinh，D=增强特征/asinh。

A和C的平均照度模型完全共用；B和D同样共用。因此平均照度只有两种特征条件，不能把重复输出视作独立证据。相对P10的均值阶段与比例阶段必须属于同一候选，推断只接收X，不能接收真实平均照度。

## 模型与选择

沿用v3的Random Forest和XGBoost两个候选参数，不扩展网格。外层留一房间（6训练/1评分）；内层GroupKFold(3)，每折4训练/2验证。对每个家族、特征组和目标形式，选择内层6房间平均原单位MAE最低的候选，完全相同时按配置声明顺序选择。外层评分在全部参数选择与训练结束后统一执行。

共504次内层基本模型拟合，外层最多112次，预计28个外层模型包。每个包包含必要的均值、比例和asinh估计器；训练结果按组共享以免重复拟合相同任务。A组预测应复现v3相应两项指标，作为代码和比较起点核对；Frozen_HistGB直接复用原有留出预测。

## 冻结的筛选标准

逐模型家族、逐目标，将B/C/D与A配对比较：

- 房间平均MAE至少下降10%；
- 至少5/7房间MAE不恶化；
- 七房间最大MAE不增加。

仅使用1e-9 lux浮点容差判断持平。三项同时满足才标记为通过开发筛选，不是工程达标，也不自动替换旧模型。逐房间报告MAE、RMSE、R²、偏差及固定1 lux尺度asinh误差。该规则没有保证所有房间改善，需特别检查BM223 P10和BM522平均照度。
