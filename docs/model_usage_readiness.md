# 模型使用就绪度与试用边界

评估日期：2026-11-08。依据：v1–v7开发实验、逐房间误差及现有模型包。本文是使用评估和接入计划，没有启动新训练或部署。

## 当前结论

可以开始研究原型的接口联调、演示和辅助比较。现有结果不足以支持对任意新房间作可靠的采光/发电承诺，也未证明动态角度推荐稳定优于固定0°。当前没有全7开发房间训练的最终部署模型、统一推断服务、Revit/Grasshopper集成或现场控制系统。

现存models/experiment_*是各验证折的模型：一般每折用6个开发房间拟合。不能随意挑一折代表最终模型，也不能把验证房间的真实平均照度传入P10预测。v7没有输出通过全部开发筛选条件，旧参考继续保留。

## 可用于试用的功能

- 展示已有按房间留出预测与模拟结果，说明模型表现和困难房间。
- 开发输入/输出接口：13项原始输入编码成15列，分别返回5项逐时预测。
- 给同一房间、同一小时枚举0°、30°、60°、90°四个角度，展示预测性能；选角规则与性能预测保持独立。
- 将模型结果作为人工审查的研究辅助信息；明确显示来源为模拟代理模型。

当前边界：同栋Tower A建筑、与既有数据相同的模拟和天气约定、07:00–18:00、四个已有角度。其他建筑、天气年、未模拟角度、PVSD距离及真实动态控制效果没有被验证。

## 接入试用版之前的具体工作

1. 冻结一个逐目标试用方案。依据7个开发房间的分组验证确定候选及参数，记录目标变换、输入字段、版本、单位和适用范围；不能根据TEST结果调参。
2. 用全部7个开发房间拟合该试用版，保存独立的版本目录和完整模型清单。它与已有6房间交叉验证模型分开；开发分数不能冒充这个新包的独立测试成绩。
3. 提供统一批量CSV/JSON预测入口。输入不含真实输出；P10相对方案使用自己的配套均值预测；输出包含Room_ID/时间/角度标识、5项性能、模型版本和适用范围提示。
4. 检查输入字段、单位、四个角度、时段及缺失值。范围提示只能表示与训练数据的相似程度，不能声称是校准过的置信概率。
5. 用TRAIN房间的既有留出预测进行接口一致性和四角度查表核对。展示采光与发电的取舍；不把模型输出直接连接到自动执行机构。
6. 方案与评分规则固定后，再按既有约定安排独立测试。BM532、BM702、BMG26本次继续封存，未预测、评分或参与训练。

## 仍待核对的来源

EPW是否与模拟一致、Hour的时间区间、太阳位置时间、模型北向、百叶零度定义、房间/窗户几何和传感器网格。使用当前字段可以制作实验接口，但这些未确认项会限制物理解释和迁移使用。资料准备见[现有模型与网格资料清单](data_requests/geometry_and_simulation_sources.md)。

## 仓库内容与复现

仓库保存代码、配置、原始数据、各轮模型、留出预测、图表及验证记录。封存测试数据的存储备份不等于解封评估。conda安装目录和缓存不进入版本管理，环境定义与精确包清单保留。

`.gitattributes`禁用自动换行转换，以保持实验文件哈希。各轮manifest保留生成时状态；README、项目状态和总索引会随后续工作更新，旧manifest中的这些汇总文档哈希对应历史版本。实验原始数据、模型包和评分结果本体原样保留。
