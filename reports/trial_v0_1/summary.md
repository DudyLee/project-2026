# 试用版0.1训练与接口验证结果

状态：已完成并可用于离线研究试用。三个TEST房间继续封存。

使用入口：[中文使用说明](../../docs/trial_v0_1_usage.md)。模型包：[models/trial_v0_1](../../models/trial_v0_1)。

## 固定模型

| 输出 | 方法 | 最终参数 |
|---|---|---|
| E_mean_lux | XGBoost / log1p | max_depth=3 |
| E_P10_lux | RandomForest / relative | max_depth=12 |
| F_300_fraction | HistGB / identity | max_leaf_nodes=15, min_samples_leaf=100 |
| F_UDI_fraction | HistGB / identity | max_leaf_nodes=15, min_samples_leaf=100 |
| PV_AC_kWh | HistGB / identity | max_leaf_nodes=15, min_samples_leaf=100 |

前两项在既定两候选中按7房间留一验证的平均MAE选参数；后三项保持v1参数。随后全部7房间122,640行拟合6个估计器（P10含自己的RF均值分支）。42次参数选择拟合＋6次全量拟合，共48次；无追加模拟。

## 软件检查

- 全部30,660个开发房间小时条件产生122,640个四角度行，核对613,200个目标值。统一接口与原实验直接推断最大差异 3.41e-13。
- CSV/JSON/Python入口、逐条/批量、模型重载、预处理列顺序及数值、TRAIN拟合输入/标签哈希检查通过。
- 30种非法输入情形拒绝；三个封存Room_ID在Python和CLI中均拒绝，未进入模型预测。元数据损坏被校验拦截。
- 推断无需原始数据库；独立模型目录在其他工作目录运行通过。输入范围提示与模型版本/哈希随结果返回。
- TEST训练、预测、评分均为0；52,560行在数值转换前跳过，原始CSV哈希保持不变。
- 当前电脑实测：加载约0.22秒；加载后单条四角度平均约0.055秒；30,660条批量约3.04秒。仅描述本机运行，不是通用性能保证。

## 使用边界

可以开始演示、同条件四角度性能比较和软件接口联调。仍未证明对任意新房间稳定准确、动态选角稳定优于固定0°，也没有最终TEST评估。未核实天气/时间/北向/百叶定义仍限制物理解释与迁移。所有范围提示都是诊断提示，不是置信概率。

本轮没有新增HTTP服务、Revit/Grasshopper插件、LLM代理或自动控制；CSV/JSON与Python接口可作为后续接入基础。
